# Creating Automated UI Tests on Android with Kotlin and Espresso

Project developed during the **Quality Assurance (QA) Experience Bootcamp** under the guidance of specialist **[Caroline Tenorio Ribeiro](https://www.linkedin.com/in/carolinetenorio/ "Caroline Tenorio Ribeiro")**.

Get the most out of this challenge by replicating the project carried out by the experts, with the goal of incorporating new features and improvements that make your tests even more robust and effective. To do this, create your own project (or reproduce the one presented by the experts) with the aim of developing your own UI test scenarios.

A lightweight frontend single-page design extending the baseline **Automated UI Testing** project concept into a functional web view environment. Built using clean **HTML5**, modern **CSS3 grid/flex custom properties**, and native modular vanilla **JavaScript**.

## Specifications & Architectural Scope

- **Advanced Semantics:** Integrated using correct layout structural blocks (`<header>`, `<main>`, `<ul>`, `<button>`).
- **Dark Mode First:** Matches system assets architecture, using custom themes driven safely by a top-tier optimization system.
- **Multilingual Context Integration:** Native real-time interface rendering for English (`EN-US`), Portuguese (`PT-BR`), and Spanish (`ES-ES`) without dependencies.
- **WCAG Compliant Accessibility Framework:** Complete integration with focus tracking, functional hidden indicators, explicit labels, and dynamic `aria-live` regions.
